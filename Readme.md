# مشروع مقرر تصميم الويب - مكتبة الحكمة

مشروع متكامل لبناء موقع إلكتروني لمكتبة تقدم خدمات بيع واستئجار الكتب والمراجع.

## التقنيات المستخدمة
- HTML5 (Semantic Elements)
- CSS3 (Flexbox & Responsive Grid & Media Queries)
- Bootstrap 5 (RTL)
- jQuery Library
- Font Awesome Icons
- Dynamic Modals & Toast Notifications

## خطوات رفع المشروع على GitHub:
1. انشئ حساباً أو سجل دخولك إلى [GitHub](https://github.com).
2. أنشئ مستودعاً جديداً (New Repository) باسم `bookstore-web-project`.
3. افتح موجه الأوامر (Terminal / Git Bash) داخل مجلد المشروع وقم بتنفيذ الأوامر التالية:

```bash
git init
git add .
git commit -m "المرحلة الأولى: إكمال كود مشروع المكتبة"
git branch -M main
git remote add origin [https://github.com/USERNAME/bookstore-web-project.git](https://github.com/USERNAME/bookstore-web-project.git)
git push -u origin main
